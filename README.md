Route Optimisation & Scenario Analysis Model
📌 Project Overview
This project is an Excel-based Route Optimisation and Scenario Analysis Model designed to support operational planning and data-driven decision-making.

The model brings together request data, route information, model inputs and scenario analysis within a structured analytical framework. It allows different operational scenarios to be compared and helps identify potential differences in cost, routing and efficiency.

The project demonstrates how large operational datasets can be transformed into structured insights that support better planning and decision-making.

🎯 Project Objectives
The key objectives of the project were to:

Structure and analyse operational request data
Develop a comprehensive route dataset
Create model inputs for scenario analysis
Compare alternative operational scenarios
Analyse cost and efficiency implications
Build a scalable Excel-based analytical model
Present complex operational information in a decision-friendly format
📊 Dataset
The project uses a synthetic dataset of over 1,000 records covering January to December 2025.

Dummy data was intentionally used so the project could demonstrate the modelling approach without exposing confidential or commercially sensitive information.

The workbook is structured around several core components:

Request
Contains the underlying operational requirements used as inputs into the model.

Routes
Provides the available route combinations and associated operational information used for analysis.

Dataset
Combines the relevant information required to analyse operational activity across the model.

Model Input
Structures the assumptions and variables required by the analytical model.

Scenario Analysis
Allows alternative scenarios to be tested and compared to understand their potential operational and cost implications.

📈 Business Value
Operational decisions often involve balancing multiple variables such as routes, demand, cost and efficiency.

This model provides a structured approach for comparing those variables under different scenarios, making it easier to understand trade-offs and identify potentially more efficient operational options.

Rather than relying solely on raw data, the model converts operational information into structured scenarios that can support more informed decision-making.
